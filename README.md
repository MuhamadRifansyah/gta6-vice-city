Solmar Bay is a complete 3D open-world crime game in the browser: drive and steal cars, outrun the Solmar Bay Police, and run five story missions across a living city — traffic, pedestrians, a wanted system, pistol combat, a HUD with a live minimap, saves, and procedural sound. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Drive with W A S D, steal a car with E, shoot with the mouse, Q for the pistol, R to reload, P to pause, M to mute.
